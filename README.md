# MusicJam

Aplicación móvil para escuchar música de forma grupal con amigos o con las personas que el usuario elija.

## Idea del producto

MusicJam busca convertir la reproducción individual en una experiencia compartida:

- crear o unirse a una sesión;
- escuchar contenido de forma coordinada;
- compartir la experiencia con otros usuarios;
- mantener una interfaz orientada a dispositivos móviles.

## Tecnologías

- Kotlin
- desarrollo móvil para Android

## Ejecución local

```bash
git clone https://github.com/Edward-uri/MusicJam.git
cd MusicJam
```

Abre el proyecto en Android Studio, sincroniza las dependencias de Gradle y ejecuta la aplicación en un emulador o dispositivo Android.
